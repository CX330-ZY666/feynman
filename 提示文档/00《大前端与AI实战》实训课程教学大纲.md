### **大学生《大前端与AI实战》实训课程教学大纲**

**课程名称：** 大前端与AI实战：费曼学习平台项目开发
**总学时：** 64学时
**课程性质：** 专业实训课程
**适用专业：** 计算机科学与技术、软件工程、网络工程、人工智能等相关专业

#### **一、 课程目标**

本课程旨在通过一个完整的、现代化的项目“费曼学习平台”，使学生：
1.  **掌握全栈开发能力：** 能够使用`Node.js` + `Express`进行后端API开发，并使用现代前端框架（如`React`）构建复杂的Web应用。
2.  **掌握AI集成能力：** 能够调用百度文心千帆等大模型API，实现智能问答、文本润色、语音识别、AI评分等功能，并掌握`RAG`（检索增强生成）技术与`MCP`（大模型上下文协议）构建领域知识库。
3.  **掌握跨平台开发能力：** 能够将Web应用打包成`桌面端`应用（使用`Electron`）和`移动端`应用（使用`PWA`或`Capacitor`）。
4.  **掌握高级可视化技术：** 能够使用`Three.js`进行3D数据可视化，使用`CesiumJS`进行3D地理信息可视化，并利用图表库实现知识图谱的可视化。
5.  **培养工程化思维：** 学习项目管理、版本控制（Git）、API设计、容器化(`Docker`)和前后端分离的开发模式，具备独立完成复杂项目的能力。

#### **二、 先修要求**

*   熟悉 `HTML`, `CSS`, `JavaScript (ES6+)` 基础。
*   对计算机网络（HTTP协议）有基本了解。
*   有使用过至少一个前端框架（如Vue, React）或后端语言者优先，但非必需。

#### **三、 技术栈概览**

*   **开发工具：** `VS Code`, `Git`, `Postman`, **`AI编程助手 (Cursor, Gemini Code Assist等)`**
*   **后端：** `Node.js`, `Express`, `MongoDB` (数据库), `JWT` (认证)
*   **前端：** `React` (或 `Vue`), `Vite` (构建工具), `Axios` (HTTP请求)
*   **AI能力：** `百度智能云千帆平台` (文心大模型, Embedding, 语音识别), **`MCP (大模型上下文协议)`**
*   **可视化：**
    *   **内容渲染：** `react-markdown` (Markdown), `KaTeX` (LaTeX), `Mermaid`
    *   **知识图谱：** `D3.js` 或 `ECharts` 或 `AntV G6`
    *   **3D可视化：** `Three.js`, `CesiumJS`
*   **跨平台：** `Electron` (桌面端), `PWA` (移动端Web应用)
*   **核心AI技术：** `RAG` (Retrieval-Augmented Generation)，使用向量数据库（如 `FAISS` 本地版或云服务）
*   **部署：** **`Docker`**, `Nginx`, `PM2`

#### **四、 教学内容与学时分配（共16次，每次4学时）**

---

**第一阶段：基础与后端构建 (12学时 / 3次)**

*   **第1次 (4学时): 导论、环境搭建与AI辅助编程初体验**
    *   **理论：** 大前端概念、课程目标、项目“费曼学习平台”整体架构介绍, **AI辅助编程工具介绍**。
    *   **实践：**
        1.  安装 `Node.js`, `VS Code`, `Git`, `Postman`。
        2.  **安装和体验AI编程助手插件 (如Gemini Code Assist)**。
        3.  初始化 `Node.js` 项目，学习 `npm`。
        4.  使用 `Express` 搭建第一个 "Hello World" 后端服务器。
        5.  Git基础：`init`, `add`, `commit`, `push`。

*   **第2次 (4学时): API与数据库设计**
    *   **理论：** RESTful API设计原则，`MongoDB`与`Mongoose`介绍。
    *   **实践：**
        1.  设计用户、知识点、复习计划等数据模型（Schema）。
        2.  使用 `Mongoose` 连接 `MongoDB` 数据库。
        3.  实现用户注册、登录的API（使用 `JWT` 进行Token认证）。

*   **第3次 (4学时): 核心功能后端开发**
    *   **理论：** CRUD操作，中间件（Middleware）概念。
    *   **实践：**
        1.  实现知识点的增、删、改、查（CRUD）API。
        2.  设计并实现API的请求验证和错误处理。
        3.  使用 `Postman` 对所有API进行测试。

---

**第二阶段：前端界面与核心交互 (16学时 / 4次)**

*   **第4次 (4学时): 前端项目初始化与基础**
    *   **理论：** `React`核心概念（组件、JSX、State、Props、Hooks）。
    *   **实践：**
        1.  使用 `Vite` 创建 `React` 项目。
        2.  创建项目路由 (`react-router-dom`)，搭建整体页面布局（导航、侧边栏、主内容区）。
        3.  创建登录、注册页面。

*   **第5次 (4学时): 前后端联调与状态管理**
    *   **理论：** 跨域（CORS）问题解决，前端状态管理（`Context API` 或 `Redux Toolkit`）。
    *   **实践：**
        1.  使用 `Axios` 封装请求模块，调用后端登录/注册API。
        2.  实现登录成功后保存`JWT Token`，并进行全局状态管理。
        3.  实现路由守卫，保护需要登录才能访问的页面。

*   **第6次 (4学时): 知识点学习模块开发**
    *   **理论：** 富文本内容的渲染策略。
    *   **实践：**
        1.  创建知识点列表页和详情页，调用后端API获取数据。
        2.  实现知识点创建/编辑的表单。
        3.  集成 `react-markdown` (渲染Markdown), `KaTeX` (渲染LaTeX), `Mermaid` (渲染流程图)。

*   **第7次 (4学时): 费曼学习法核心流程（录音与转文字）**
    *   **理论：** 浏览器 `MediaRecorder` API。
    *   **实践：**
        1.  在知识点学习页面，实现录音功能（开始、暂停、停止）。
        2.  将录制的音频文件（Blob）上传到后端。
        3.  后端接收音频文件，调用**百度语音识别API**，将音频转换为文字。
        4.  前端展示转录后的文字。

---

**第三阶段：AI深度集成 (16学时 / 4次)**

*   **第8次 (4学时): AI文本润色与评价**
    *   **理论：** Prompt Engineering基础，大语言模型（LLM）API调用。
    *   **实践：**
        1.  注册百度智能云，获取千帆大模型API Key。
        2.  将语音转录的文字发送给**文心大模型API**，设计Prompt，让AI进行文本润色。
        3.  设计评价Prompt，让AI根据原文和学生的复述文字进行打分和评价。

*   **第9次 (4-学时): AI出题与测评系统**
    *   **理论：** AI生成内容的控制与多样性。
    *   **实践：**
        1.  根据当前知识点内容，请求AI（文心大模型）生成不同难度（基础、中等、困难）的题目。
        2.  学生回答问题，将答案提交给AI进行评判和打分。
        3.  记录测评结果，如果未通过，将该知识点加入复习列表。

*   **第10次 (4学时): RAG与私有知识库 (Part 1 - 基础)**
    *   **理论：** RAG（检索增强生成）原理，文本向量化（Embedding）概念。
    *   **实践：**
        1.  后端实现一个流程：当创建或更新知识点时，将其内容分块（Chunking）。
        2.  调用**百度Embedding API**将文本块转换为向量。
        3.  将文本块和其对应的向量存入本地向量数据库（如`FAISS`）。

*   **第11次 (4学时): RAG与私有知识库 (Part 2 - 检索与生成)**
    *   **理论：** 向量相似度搜索, **大模型上下文协议(MCP)介绍**。
    *   **实践：**
        1.  创建一个AI Agent问答界面。
        2.  用户提问后，将问题向量化并在向量库中进行相似度搜索。
        3.  **使用MCP优化Prompt结构**，将召回的文本块和用户问题组合成一个增强的Prompt，发送给文心大模型，生成基于知识库的精准回答。

---

**第四阶段：高级可视化与跨平台部署 (20学时 / 5次)**

*   **第12次 (4学时): 知识图谱可视化**
    *   **理论：** 图（Graph）数据结构，力导向图布局算法。
    *   **实践：**
        1.  在后端构建知识点之间关联关系的数据接口。
        2.  前端使用 `AntV G6` 或 `ECharts` 的关系图，将知识点及其关联关系可视化为知识图谱。
        3.  实现图谱的交互（点击节点高亮、查看详情等）。

*   **第13次 (4学时): 3D可视化入门与Three.js**
    *   **理论：** `Three.js` 核心概念（场景、相机、渲染器、几何体、材质）。
    *   **实践：**
        1.  创建一个基础的3D场景。
        2.  尝试将知识图谱用3D形式展现（例如，知识点作为星球，关系作为连线）。
        3.  为3D场景添加交互（鼠标控制视角、点击交互）。

*   **第14次 (4学时): 3D地球与CesiumJS**
    *   **理论：** `CesiumJS` 介绍，GIS（地理信息系统）基础。
    *   **实践：**
        1.  集成`CesiumJS`，创建一个3D数字地球。
        2.  （可选趣味功能）允许学生将知识点“钉”在地球的某个位置上，并进行展示。
        3.  学习在地球上添加实体（Entity）、标签和模型。

*   **第15次 (4学时): 跨平台打包**
    *   **理论：** `Electron` 架构（主进程与渲染进程），PWA（Progressive Web App）核心技术（Service Worker, Manifest）。
    *   **实践：**
        1.  使用 `Electron` 将已完成的Web应用打包成一个可执行的桌面应用（Windows, macOS）。
        2.  为Web应用添加 `manifest.json` 和 `Service Worker`，使其成为一个可安装到手机主屏的PWA应用。

*   **第16次 (4学时): 项目总结、容器化部署与展示**
    *   **理论：** **使用Docker进行容器化部署的基本原理和流程**。
    *   **实践：**
        1.  项目代码整理、优化和构建。
        2.  **编写`Dockerfile`，（理论上）将前后端应用打包成Docker镜像**。
        3.  **最终项目汇报与展示**，学生分组展示自己的“费曼学习平台”成果，分享开发心得。

#### **五、 考核方式**

*   **平时表现 (20%)：** 包括出勤、课堂互动、提问与回答。
*   **阶段作业 (30%)：** 在每个阶段结束后，提交该阶段完成的功能模块代码，进行检查和评分。
*   **最终大作业 (50%)：** 提交完整的“费曼学习平台”项目，包括源代码、演示视频和一份简单的项目报告。要求功能完善、界面美观、代码规范。
